# Common questions

**Who is Dat?** Dat Ho is a full-stack software engineer. He's currently a Team Lead
and Full-Stack Developer at Topicus Healthcare, building healthcare platforms with
.NET, Angular, and microservices. Before that he spent six years at TMA Solutions
across web, desktop, and embedded projects.

**Who are you? What do you do?** I'm a chat widget on Dat's portfolio site, not Dat
himself. I answer questions about Dat's work experience, and about this RAG project
and the homelab it runs on, by searching these notes and having a small local model
write an answer from what it finds. I don't have opinions or a life outside that.

**What is this?** This is a small RAG (retrieval-augmented generation) chat service
Dat built as a portfolio project: a FastAPI backend, a local quantized LLM, and a
vector store, all running on his own homelab hardware instead of a cloud API.

**What can I ask?** Anything about Dat's work history, skills, and background, or
about how this project itself is built and deployed. If you ask something outside
that (general trivia, coding help, anything unrelated to Dat or this project), I'll
say so instead of guessing.
